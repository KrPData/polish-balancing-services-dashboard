# polish-balancing-services-dashboard


https://www.youtube.com/watch?v=N5ZvNo1WG4s&feature=youtu.be

An interactive report providing an overview of the Polish ancillary services market. It includes statistics on balancing power reserves with upward and downward activation, as well as a breakdown by reserve type. The report is divided into a strategic section, for viewing annual/monthly data, and an operational section for daily trading activities.

The entire report is based on live data from the API of Polish power grid Operator (PSE), with an implemented ETL process. Only a presentation version has been posted on YouTube.
